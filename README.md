# Deepak Aher — Professional Anchor & Event Host Portfolio

A complete, premium, modern, fully responsive, and bilingual (English / मराठी) personal brand portfolio website crafted for **Deepak Aher**, Professional Anchor & Event Host based in Maharashtra.

---

## 🌟 Visual Design System
- **Background**: Warm Ivory White (`#FAF8F5`) with subtle light-blue and golden radial gradients.
- **Primary Text**: Deep Midnight Navy (`#0D1B2A`, `#2C3E50`).
- **Accents**: Imperial Gold (`#C59B27`, `#E8C868`) and Rich Plum / Wine (`#5A1838`, `#7A254E`).
- **Typography**: Editorial Serif (`Playfair Display`) & Modern Sans-Serif (`Plus Jakarta Sans`), seamlessly paired with `Noto Sans Devanagari` for crisp Marathi script rendering.
- **Aesthetic**: Generous whitespace, refined SVG icons, gold filigree corners, smooth micro-interactions, and glassmorphism.

---

## 🌐 Instant Bilingual Support (English & मराठी)
- **Interactive Switcher**: Dedicated toggle pill (`EN / मराठी`) in both the desktop sticky navbar and the mobile menu drawer.
- **Instant Client-Side Switching**: Toggling between languages updates all text across the entire page immediately without page reloads.
- **Persistence**: Automatically preserves the visitor's choice in `localStorage` (`deepak_lang`) so refreshes and return visits remember the chosen language.
- **100% Comprehensive Coverage**: 238 translation keys covering navigation, hero section, about biography, all 11 event services, experience timeline, press clippings, photo gallery, Why Choose Me pillars, contact booking form (including labels, placeholders, select options, validation messages, and success modal), and footer.
- **Culturally Authentic Marathi**: Dignified, eloquent phrasing suitable for Maharashtrian cultural ceremonies and professional hosting.

## ⚙️ How to Update Content & Settings

- **Translations**: Modify or add wording in [`assets/js/translations.js`](file:///c:/Users/Aadi/OneDrive/Documents/websites/Dipak/assets/js/translations.js).
- **Owner Verification & Integration**: In [`assets/js/config.js`](file:///c:/Users/Aadi/OneDrive/Documents/websites/Dipak/assets/js/config.js):
  - Set `isPhoneConfirmed: true` once verified by Deepak Aher to activate direct phone links.
  - Set `formEndpointType: "formspree"` or `"emailjs"` to connect your preferred form backend.
